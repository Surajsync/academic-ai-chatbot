# AI Chatbot System

## Overview
A FastAPI based chatbot system with authentication and admin dashboard.

## Tech Stack
- FastAPI
- PostgreSQL
- Python
- HTML / CSS

## Features
- User authentication
- Chatbot API
- Admin dashboard
- FAQ database

## Run Locally

Install dependencies

pip install -r requirements.txt

Run server

uvicorn backend.app:app --reload

Open API docs

http://127.0.0.1:8000/docs
